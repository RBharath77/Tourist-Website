# 🌍 Tourism Website

## 📌 About

**Tourism Website** is a responsive web application designed to help users explore heritage destinations, browse travel galleries, and access booking information through a simple and attractive interface.

---

# ✨ Features

* 🏛️ Heritage Destination Pages
* 🖼️ Image Gallery
* 🏠 Responsive Home Page
* 📅 Online Booking Page
* 🎨 Clean and Modern User Interface
* 📱 Mobile-Friendly Design

---

# 🛠️ Technologies Used

* HTML5
* CSS3

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/tourism-website.git
```

### Run the Project

1. Open the project folder.
2. Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
